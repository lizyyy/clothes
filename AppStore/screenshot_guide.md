# App Store 截图准备指南

## 截图尺寸要求

### iPhone 截图（必需）

| 尺寸 | 分辨率 | 用途 |
|------|--------|------|
| 6.7" | 1290 x 2796 | iPhone 15 Pro Max / 16 Pro Max |
| 6.5" | 1284 x 2778 | iPhone 14 Pro Max |
| 5.5" | 1242 x 2208 | iPhone 8 Plus |

### iPad 截图（可选）

| 尺寸 | 分辨率 |
|------|--------|
| 12.9" | 2048 x 2732 |
| 11" | 1668 x 2388 |

## 截图制作工具

### 方式1：Xcode模拟器 + 截图工具
```bash
# 使用模拟器截图
xcrun simctl io booted screenshot screenshot.png
```

### 方式2：Fastlane快照
```ruby
# Fastfile配置
snapshot(
  devices: ["iPhone 15 Pro Max", "iPhone 14 Pro Max"],
  languages: ["zh-Hans"],
  output_directory: "./screenshots"
)
```

### 方式3：手动设计
- 使用Figma/Sketch设计
- 导出符合尺寸的PNG/JPG

## 截图规范

- **格式**：PNG或JPG
- **色彩空间**：sRGB
- **文件大小**：每张不超过 20MB
- **内容**：不得包含状态栏、导航栏等系统UI

## 预览视频（可选）

- **格式**：H.264 或 ProRes 422
- **分辨率**：与截图一致
- **时长**：15-30秒
- **文件大小**：不超过 500MB
